MisioCache — ustawienia i diagnostyka

Stan funkcjonalności

Tryb diagnostyczny (seria 0.1). Wtyczka instaluje własny panel i zachowuje planowane ustawienia, ale nie zapisuje jeszcze filmu w cache, nie pobiera fragmentów w tle i nie zmienia odtwarzacza Jellyfina.

Przyszła integracja wymaga zgodnego adaptera odtwarzającego na urządzeniu. Instalacja DLL na NAS-ie nie daje dostępu do pamięci telefonu.

Aktualizacje

MisioCache ma osobne repozytorium kumblip/MisioCache oraz własny manifest aktualizacji. Po pierwszym GitHub Release dodaj adres repozytorium w katalogu wtyczek Jellyfina. Kolejne wydania publikuje GitHub Actions z automatycznym numerowaniem.
